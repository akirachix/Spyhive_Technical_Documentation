# Bloom

## Technical Documentation

Technical documentation for the Bloom maternal health platform.

---

##  Welcome to Bloom

Bloom is a maternal health platform designed to support mothers,
caregivers, Community Health Promoters, and administrators through
a connected digital ecosystem.

This documentation provides the technical information required
to understand, develop, test, deploy, and maintain the Bloom platform.
