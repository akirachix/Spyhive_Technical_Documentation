# Getting Started

This guide explains how to set up the Bloom development environment,
run the backend, mobile application and administrative dashboard locally,
and verify that the platform is running correctly.

The repository contains the technical documentation, backend,
mobile application, dashboard, design resources and QA materials
for the Bloom platform.

---

## 1. Prerequisites

Before setting up Bloom, install the following tools.

### Required

| Tool | Purpose |
|---|---|
| Git | Clone the repository and manage source code |
| Python | Run the Bloom FastAPI backend |
| PostgreSQL | Run the Bloom development database |
| Flutter SDK | Build and run the Bloom mobile application |
| Dart | Required by Flutter |
| Node.js | Run the Bloom administrative dashboard |
| npm | Install dashboard dependencies |

Make sure each tool is available from your terminal.

### Verify the installations

Run:

```bash  

- git --version  

- python --version  

- psql --version  

- flutter --version 

- dart --version  

- node --version  

- npm --version
